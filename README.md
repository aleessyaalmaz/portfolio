# Aleessya Almaz binti Razali | Portfolio

A game-themed personal portfolio website showcasing my projects, skills, career journey and community work.

🔗 **Live site:** https://aleessyaalmaz.github.io/portfolio/

> 🚧 **Work in progress.** The portfolio is still being built. Some sections use placeholder content and will be updated as the site is completed.

## About

I am a Bachelor of Computer Science (Multimedia Computing) graduate from UNIMAS with a passion for games, UI/UX and creative technology. This portfolio is designed like a game world, with a playful theme and a small interactive game element, to show who I am as a developer and designer.

## Sections

- **Hero:** introduction with quick actions (View Projects, Download Resume, Hire Player)
- **Skill Tree:** skills grouped into Game Development, Programming & Web, Tools & Productivity, Technical Domains and Soft Skills & Languages
- **Career:** work experience and internships
- **Projects:** card grid with category filters and scrollable picture galleries
- **Programs & Community Initiatives:** volunteering and community programmes
- **Education:** academic background
- **Contact:** a "get in touch" section

## Features

- Game-inspired design with a small game element on the page
- Light (day) mode by default
- Filterable project cards with image galleries and popup previews
- Alternating coloured section bands with rounded cards

## Tech stack

- HTML, CSS and JavaScript
- Hosted on GitHub Pages

## Project structure

```
index.html     The portfolio page
profile.jpg    Profile picture
README.md      This file
```

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/aleessyaalmaz/portfolio.git
   ```
2. Open `index.html` in your browser. No build step is needed.
